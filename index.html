¿Qué es Git?

Git es un sistema de control de versiones distribuido que permite rastrear cambios en el código fuente.

¿Qué es GitHub?

GitHub es una plataforma en la nube que aloja repositorios Git y facilita la colaboración entre desarrolladores.

¿Qué son las Ramas?

Las ramas permiten trabajar en nuevas funcionalidades sin afectar el código principal del proyecto.
